This is code based on suggestions from community members on how the saber could function. It is not guaranteed to work perfectly, it's more of a starting point for if you want to experiment and make something for yourself.

`LightsaberWithColorArray.ino`
- Single click (still) plays activation/deactivation animation
- Double click changes the saber to the next color in a preset list of colors (starting over when hitting the end)
